# Contributing

Thanks for helping. The most useful contributions are corrections to the English, and
reports of text that does not fit or looks wrong in game.

## Reporting a problem

Open an issue with the "Translation or display problem" template. Include:

- where it happens (route, chapter, screen) and the line as shown in game;
- a screenshot if you can (PPSSPP: F12, or the screenshot button on Android);
- for a translation error, what it should say, and the Japanese if you know it.

Do not attach ISOs, extracted game files or full script dumps.

## Sending a change

1. Read [AGENTS.md](AGENTS.md): the hard rules apply to everyone, people and agents.
2. Set up and make a first build: [docs/SETUP.md](docs/SETUP.md).
3. Work on a branch named `<type>/<slug>` (`fix/apollon-ch3-typos`,
   `feat/edit-quiz-titles`), with conventional commits.
4. For translation edits follow [docs/TRANSLATION.md](docs/TRANSLATION.md); for engine
   or image work [docs/HANDOFF.md](docs/HANDOFF.md) and
   [docs/FORMATS.md](docs/FORMATS.md).
5. Before opening a pull request: `python tools/check.py --iso <original.iso>` reports 0
   errors, the build runs, and visible changes were looked at in game
   ([docs/TESTING.md](docs/TESTING.md)).

Pull requests change sources only (`translation/`, `tools/`, `asm/`, docs). The
`patch/` folder is regenerated by the maintainer for each release
([docs/RELEASE.md](docs/RELEASE.md)).

## What may be committed

English text, tools, patches, specs and docs. Never the ISO or anything extracted from
it: Japanese script text, the decrypted EBOOT, textures, exported PNGs or screenshots
of game data beyond what an issue needs. `work/` is ignored for this reason.
